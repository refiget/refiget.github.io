4. Median of Two Sorted Arrays

4. Median of Two Sorted Arrays

给定两个大小分别为 m 和 n 的正序（从小到大）数组 nums1 和 nums2。请找出并返回这两个正序数组的中位数。

算法的时间复杂度应该为 O(log(m + n))。

示例 1：

  • 输入：nums1 = [1, 3]，nums2 = [2]
  • 输出：2.00000
  • 解释：合并数组为 [1, 2, 3]，中位数为 2。

示例 2：

  • 输入：nums1 = [1, 2]，nums2 = [3, 4]
  • 输出：2.50000
  • 解释：合并数组为 [1, 2, 3, 4]，中位数为 (2 + 3) / 2 = 2.5。

转化为查找第 k 小的元素

我们可以把问题转化为：给定两个升序数组 A 和 B（这里假设元素都是自然数），找到合并后第 k 小的元素。这里的 k 是从 1 开始计数的序号。

因为数组都是升序的，较小的元素会排在左边。比如 A 的长度是 3，B 的长度是 4，总长度是 7。假设我们需要找到第 4 小的元素，就把最小的 4 个元素分到左边：从 A 中取 i 个，从 B 中取 j 个，使得 i + j = 4。这样，左边一共有 4 个元素，第 4 小的元素就是左边最大的元素，也就是 A[i - 1] 和 B[j - 1] 中较大的一个。

因为 i + j = k，我们只需要确定 i，就能得到 j = k - i。接下来的问题就是如何保证选择的 i 合法。

因为我们是通过选择 i 来切分数组，所以 i 可能太大，也可能太小。

什么时候 i 会太小呢？i 太小说明从 A 中取的元素不够多。假设 A = [1, 2, 3]，我们只取了 1 和 2，也就是 i = 2，但实际上还需要取 3。这说明没有取到的 3 仍然属于最小的前 k 个元素。为什么会把 i 取小呢？因为我们从 B 中相对多取了一个元素。此时，如果 B[j - 1] > A[i]，就说明 B 中左边最大的元素，比 A 中左边之后的第一个元素还大。我们应该少取一个 B 中的元素，改为多取一个 A 中的元素，所以 i 选小了。

那 i 选大的情况，就是选小情况的对称。如果 A[i - 1] > B[j]，说明 A 中左边最大的元素，比 B 中左边之后的第一个元素还大，因此 i 选大了。

用二分查找调整切分位置

接下来我们讨论如何调整 i 的选择。

相信很多人入门编程时都写过猜数字游戏：猜 0 到 100 之间的整数。猜对了就胜利；猜大了就返回“too large”，反之则返回“too small”。一个好的猜法是先猜 50，然后根据回答，在 0 到 49 或者 51 到 100 之间继续猜。这里可以抽象出这样一个思路：

求解区间：[0, 100]
if answer == secret_number:
    print("WIN!")
elif answer > secret_number:
    调整求解区间上界
else:
    调整求解区间下界

用数学的术语来说，我们的迭代过程是在不断缩小一个闭区间，最后找到符合条件的位置。

确定搜索范围

基于以上讨论，我们需要找到 i 的搜索范围。

首先，i 表示从 A 中取出的元素个数，所以 0 <= i <= m，其中 m 是 A 的长度。i 等于 0 表示一个元素也不取。同时，j 表示从 B 中取出的元素个数，所以 0 <= j <= n，其中 n 是 B 的长度。又因为 j = k - i，所以 0 <= k - i <= n。结合 0 <= i <= m，得到 i 的搜索范围：

left  = max(0, k - n)
right = min(k, m)

这里的 k 是第 k 小的序号，同时也是需要放在左边的元素个数。两者都是从 1 开始计数的序号和元素数量；而数组下标从 0 开始，所以左边最后一个元素的下标是 i - 1 或 j - 1。

现在我们找到了合法的切分位置。第 k 小的元素就是 A[i - 1] 和 B[j - 1] 中较大的一个。

根据切分位置调整搜索范围

现在整理代码：

# 1. 设置搜索范围
left = max(0, k - len(B))
right = min(k, len(A))

# 2. 二分查找
while left <= right:
    i = (left + right) // 2
    j = k - i

    # i 太小
    if B[j - 1] > A[i]:
        left = i + 1
    # i 太大
    elif A[i - 1] > B[j]:
        right = i - 1
    # 找到了满足条件的 i
    else:
        break
i = left  # 找到目标 i

处理数组边界

注意，代码中会访问 B[j - 1]、A[i - 1]、A[i] 和 B[j]。

对于 A[i - 1] 和 B[j - 1]，需要考虑 i = 0 或 j = 0 的情况。这表示对应数组左边没有取任何元素。

对于 A[i] 和 B[j]，需要考虑 i = len(A) 或 j = len(B) 的情况。这表示对应数组中的元素已经全部取完。

当左边没有取元素时，可以把对应的左侧值看作比任何数都小。这样它不会导致我们误以为从该数组取少了。

当数组中的元素全部取完时，可以把对应的右侧值看作比任何数都大。这样它不会导致我们误以为从该数组取多了。

对应的边界值可以这样表示：

A_left = A[i - 1] if i > 0 else float("-inf")
A_right = A[i] if i < len(A) else float("inf")

B_left = B[j - 1] if j > 0 else float("-inf")
B_right = B[j] if j < len(B) else float("inf")

完整代码

把边界处理放进二分查找，完整代码如下：

def findKth(A: list[int], B: list[int], k: int) -> int:
    # 1. 确定 i 的搜索范围
    left = max(0, k - len(B))
    right = min(k, len(A))

    # 2. 二分查找合法的切分位置
    while left <= right:
        i = (left + right) // 2
        j = k - i

        # 处理四种边界
        A_left = A[i - 1] if i > 0 else float("-inf")
        A_right = A[i] if i < len(A) else float("inf")

        B_left = B[j - 1] if j > 0 else float("-inf")
        B_right = B[j] if j < len(B) else float("inf")

        # i 太小，需要从 A 多取一些
        if B_left > A_right:
            left = i + 1

        # i 太大，需要从 A 少取一些
        elif A_left > B_right:
            right = i - 1

        # 找到了合法切分
        else:
            return max(A_left, B_left)

回到中位数

有了这个方法，相信解决原题就是轻而易举了。对于原题，合并后总元素个数为 m + n：总数为奇数时，中位数是第 (m + n + 1) // 2 小的元素；总数为偶数时，中位数是第 (m + n) // 2 小和第 (m + n) // 2 + 1 小的元素的平均值。
